# DAR — Mobile App UI (SVG, Figma-ready)

Sustainable furniture marketplace — *"A home that feels like you."*
Design: Rawan Jarada

## Screens (390 × 844)
1. `01-home.svg` — Home: search, categories, featured product, new arrivals, tab bar.
2. `02-browse.svg` — Browse: category filter chips, sort/filter row, 2-column product grid.
3. `03-product-details.svg` — Product details: gallery, rating, material chips, color, quantity, AR + Add to Cart.
4. `04-ar-preview.svg` — AR room preview: placement guide, rotate control, fit check and dimensions.
5. `05-cart.svg` — Cart: items, promo code, summary with carbon-neutral delivery, checkout.
6. `06-checkout-confirmed.svg` — Order confirmed: order number, delivery estimate, eco impact, next actions.

`png/` holds 2x previews (780 × 1688) and `overview.png`, a presentation board.

## How to use in Figma
Drag the `.svg` files onto the canvas (or use Import) — do not use File → Place image. Each screen arrives as an editable frame with named layers, and text stays editable. Install Playfair Display and Inter if Figma asks.
