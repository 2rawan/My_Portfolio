# LAMSA — Mobile App UI (SVG screens)

"Small acts. Real impact." A community donation app. Design by Rawan Jarada.

## Screens (390 × 844)
1. `01-onboarding.svg` — Welcome screen with hero photo, pager and sign-in actions.
2. `02-home.svg` — Greeting, search, categories, featured campaign and nearby causes.
3. `03-cause-details.svg` — Cause cover, verified badge, organizer, progress, story and sticky Donate button.
4. `04-donate.svg` — Secure Giving: amount stepper, presets, frequency toggle, note and saved card.
5. `05-success.svg` — Thank-you confirmation with what the gift funds and next actions.
6. `06-impact.svg` — Personal impact dashboard: period switch, stat tiles, monthly chart, updates.

`png/` holds 2x previews of every screen and `overview.png` (presentation board).

## Font

## How to use in Figma
Drag the .svg files onto the canvas (or File → Place image… is NOT it — use drag & drop / Import). Each screen arrives as an editable frame with named layers, and text stays editable. Install Plus Jakarta Sans if Figma asks.
