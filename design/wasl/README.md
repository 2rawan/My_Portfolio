# WASL — Your city, within reach.

Accessible city transit planner · UI screens (390 × 844, iPhone 14/15) · Author: Rawan Jarada

## Screens
| File | Purpose |
|---|---|
| `01-search-route.svg` | Plan a trip: From/To, transport modes, step-free toggle, popular destinations |
| `02-route-options.svg` | Compare routes with timelines and accessibility badges |
| `03-live-trip.svg` | Live trip on a vector map with next stop and stop timeline |
| `04-stop-alerts.svg` | Station arrivals board with lift status and service alert |
| `05-saved-places.svg` | Saved places and quick-start journeys |
| `06-accessibility-settings.svg` | Step-free, contrast, text size, screen reader and voice settings |

`png/` contains 2x previews of each screen and `overview.png`, a presentation board.

## Palette
- Navy `#0B2D5B` — primary text / dark surfaces
- Cobalt Blue `#2563EB` — interactive
- Mint Green `#10B981` — success / live (text uses `#047857` for AA contrast)
- Mist Grey `#E5EAF0` — borders / dividers
- Surface `#F5F7FB`, White `#FFFFFF`
- Muted text `#5B6B82`, Alert Amber `#F59E0B`

## Font
Plus Jakarta Sans (Google Fonts) — H1 48/56 Bold … Caption 14/20 Regular.

## How to use in Figma
Drag the .svg files onto the canvas (or File → Place image… is NOT it — use drag & drop / Import); each screen arrives as an editable frame with named layers; text stays editable; install Plus Jakarta Sans if Figma asks.
