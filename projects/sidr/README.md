# SIDR — Natural Skincare

A responsive, static e-commerce concept landing page for **SIDR**, a natural skincare brand: hero, product essentials, ingredients, rituals, testimonial and footer.

**Live demo:** https://2rawan.github.io/My_Portfolio/projects/sidr/

## Features
- Working shopping cart: add to cart, bag count badge, slide-out drawer with quantity +/-, remove and subtotal
- Cart persisted in `localStorage`
- Smooth-scroll navigation and mobile hamburger menu
- Reveal-on-scroll animations (respects reduced motion)
- Accessible: semantic HTML, alt text, focus styles, ARIA labels, keyboard support (Esc closes the cart)
- Responsive down to 360px

## Tech
HTML, CSS and vanilla JavaScript. No build step, no frameworks. Fonts: Cormorant Garamond and Jost (Google Fonts).

## Run locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server
```

then visit http://localhost:8000.
