# My_Portfolio

Personal portfolio of Rawan Jarada — front-end developer & UI/UX designer.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Hosting

Asset paths are absolute (`/assets/...`), so the site must be served from the domain root
(e.g. a custom domain on GitHub Pages, Netlify, or Vercel).
