# My_Portfolio

Personal portfolio of Rawan Jarada — front-end developer & UI/UX designer.

The site is configured for GitHub Pages at `https://2rawan.github.io/My_Portfolio/`.
All paths are prefixed with `/My_Portfolio`, so to preview locally serve the parent folder:
`python3 -m http.server 8000` from one level up, then open http://localhost:8000/My_Portfolio/
